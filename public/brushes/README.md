# Calligraphy brush cursors

Five transparent brush assets based on the owner's supplied “Traditional Chinese Calligraphy Brush Collection.png”. Prepared with the built-in imagegen tool, then resized to 256px-wide WebP files (about 16KB each) for browser delivery. Original generated PNGs remain in the Codex generated_images directory.

Selection: wood-red (row 1, column 1), porcelain-blue (row 1, column 4), jade-green (row 1, column 5), violet (row 2, column 3), blossom-pink (row 3, column 5).

Prompt template: “Use case: background-extraction. Extract ONLY the [selected brush description] from the reference collection, as ONE isolated individual brush on a genuinely transparent background. Preserve its original attractive 3D emoji style and recognizable colors. Orient diagonally with precise pointed tip at bottom-left, handle at top-right. Entire brush and tassel inside frame, tightly framed with small padding. No glow, no ground shadow, no text, no additional brushes. Intended use: small animated website cursor.”

Per-asset descriptions: wooden brown handle with red tassel; blue-and-white porcelain with blue tassel; pale celadon carved jade with green tassel; purple lacquer with pale blue flowers and purple tassel; pale pink porcelain with cherry blossoms and pink tassel.

Each cursor has a calibrated tip origin in src/components/HomeExperience.tsx. Decorative cursors do not replace the visitor's pointer.
